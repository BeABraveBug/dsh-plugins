# 书架与阅读器

在 DeepSeek Harness 中管理和阅读本地 PDF、EPUB、TXT、Markdown，支持阅读续接、多份 Markdown 笔记和基于文字摘录的 AI 问答。

插件只引用原文件位置，不复制、修改、移动或删除原书。书目、阅读状态、笔记和问答记录保存在 DSH 运行数据目录。

## 安装

需要 Node.js `^22.19.0 || >=24.0.0`，以及 DSH `>=0.2.1-rc.2 <0.3.0`。已验证的宿主版本为 `0.2.1-rc.5`，浏览器环境为 Chromium；其他 DSH 版本、Windows 和远程部署尚未逐一验证。

包名为 `dsh-bookshelf`。在本仓库根目录执行：

```sh
pnpm install
pnpm --filter dsh-bookshelf build
dsh plugin --profile web add "$PWD/plugins/bookshelf"
```

将 `web` 替换为实际使用的 profile。`lib/` 不随源码保存，新 checkout 和源码更新后需要构建，再按宿主方式重新加载插件。升级、卸载及其他安装方式见[安装与升级插件](../../docs/installation.md)。

## 使用

### 添加与管理书籍

从 DSH 侧栏打开“书架”，选择“添加文件”或“添加目录”。目录只扫描第一层支持的文件，不持续监听变化；后续新增文件需再次添加。相同绝对路径不会重复入架，也不会重置已有进度；符号链接或不同大小写的路径可能被视为不同书目。

书架支持搜索和最近打开排序，固定每页 4 列 × 3 行、最多 12 本。添加窗口的“已添加”视图可查看已有路径并移出。普通浏览器通常无法取得拖入文件的本机路径，此时请使用“添加文件”；仅在宿主提供路径时支持直接拖入。

载入书架或点击“重新检查”时检查文件可用性。缺失、权限不足或暂时无法访问会显示提示，不会自动移出记录。

“移出书架”需要确认，只移除书目、阅读进度和已读状态，原文件、笔记及问答记录保留。同一路径重新添加时恢复笔记和问答关联，阅读进度与已读状态从头开始。移出不等于删除原书或清除个人记录。

### 阅读与续接

点击书籍打开阅读器，阅读位置自动保存；返回书架可查看最新进度。“已读完”由用户手动标记或取消，翻到末尾不会自动标记，也不因标记而重置位置。

| 格式 | 阅读方式 | 续读位置 |
| --- | --- | --- |
| PDF | 单页显示，支持工具栏翻页、页码跳转、两侧悬停翻页、缩放和文字选择 | 页码、页内位置及每本书独立的缩放比例 |
| EPUB | 连续滚动，禁用书内脚本 | CFI 位置及百分比 |
| TXT | UTF-8 只读文本 | 滚动比例 |
| Markdown | 清理 HTML 后只读呈现；支持 GFM、KaTeX 公式与 Mermaid 图表 | 滚动比例 |

PDF 鼠标移至阅读区两侧时显示翻页入口，点击才翻页；首末页不能越界，工具栏入口保留。调整笔记侧栏宽度后，PDF 按正文可用区域重新适应，保留相对缩放。

### 笔记与问答

阅读器的“笔记”标签支持为一本书创建多份 Markdown 笔记，修改标题、编辑、预览和确认删除；预览支持 GFM、KaTeX 公式与 Mermaid 图表。笔记自动保存；切换或关闭前等待保存，失败时保留输入并提供重试。书架的“笔记数据”入口可查看保留的笔记并按书删除，不影响原书或阅读进度。

在“问答”标签查看本轮文字附件，选择 DSH 已配置模型后提问。有选中文字时优先使用选区；否则 PDF 使用当前页文字，EPUB 使用当前章节的有界摘录，TXT/Markdown 按滚动位置提取文字窗口。附件可展开查看或移除；当前实现需要文字上下文才能发送。

模型选择按书保存，重新打开继续使用；模型失效时需重新选择。消息列表可在重开后恢复，并可清空该书对话。助手回答支持 Markdown 展示、复制和追加到当前笔记。

PDF 可截取正文可视区域并预览、保留或取消。截图仅保存在本次阅读会话内，不持久化，也不发送给模型。

## 封面

PDF 优先使用同目录的侧车图片，否则显示第一页缩略图；EPUB 优先使用内嵌封面，缺失时查找侧车图片；TXT 和 Markdown 使用侧车图片。侧车文件使用去掉书籍扩展名后的名字，例如 `书籍名.cover.jpg` 或 `书籍名.png`，支持 jpg/jpeg/png/webp/gif/svg/avif/bmp。

macOS 的 PDF 缩略图优先使用 Quick Look，不可用时回退到浏览器渲染。浏览器读取 PDF 封面有 6 MB 分段读取预算；读取失败时仅对不超过 5 MB 的文件尝试整本读取。无法提取或渲染封面时显示格式占位图，不影响阅读和进度。封面按需读取，不创建书籍副本，也不写入书架记录。

## 数据与隐私

运行数据位于 `$DSH_HOME/bookshelf/`；未设置 `DSH_HOME` 时默认为 `~/.dsh/bookshelf/`。

| 文件 | 内容 |
| --- | --- |
| `library.json` | 书目、阅读位置、缩放和已读状态 |
| `notes.json` | 笔记及每本书的模型选择 |
| `conversations.json` | 按书保存的问答消息 |

书架不按聊天或工作目录分库；连接到同一运行数据目录时使用同一套记录。原书保持在用户选择的位置，由 DSH 宿主只读访问。

主动提问会将本轮问题和附带文字交给所选的 DSH 模型服务处理；模型凭据由 DSH 管理，不交给书架浏览器界面。恢复本地消息列表不表示历史已发送给模型：当前每次请求只包含本轮问题和文字上下文。

保存失败会显示错误，不将未保存状态视为成功；损坏的记录不会被自动清空重建。不支持多个 DSH 进程同时修改同一数据目录。备份或迁移时应保留整个 `bookshelf/` 数据目录，书籍原文件另行保管。

## 已知限制

- 独立页目前不能保证与 DSH 主题完整一致，固定主题、系统切换或缓存条件下可能显示不同配色。
- 问答尚不支持将历史轮次交给模型连续追问、保存逐轮来源快照、发送截图，或在原书移出后通过独立入口管理对话。
- 笔记没有创建位置跳转；回答只能追加到当前笔记，不能直接选择其他笔记或新建目标。
- EPUB 上下文是章节摘录，TXT/Markdown 上下文是按滚动比例提取的文字窗口，均不保证等同于精确可见内容。EPUB 在排版或窗口变化后恢复的位置可能有偏差。
- PDF 采用单页视图，没有连续分页滚动、目录、搜索或注释。未内嵌字体依赖系统字体；缺少字形或特殊字体的 PDF 可能显示异常。加密或非标准 EPUB 的封面可能无法识别。
- 窄窗口下书架仍为 4 列，不切换列数。添加窗口只管理添加和移出，不支持重命名、移动或打开原路径。
- 不提供 OCR、朗读、云同步、原书正文编辑、书签或阅读主题设置。超大 EPUB、所有 PDF 字体及特殊 EPUB 容器未做全面验证。
- 独立书架页与用户主动浏览器全屏已提供入口；全屏不支持或未验证的浏览器会保留独立页阅读。通用右侧 AI 会话插件接入尚未提供，书架自带问答窗口暂停扩展。
