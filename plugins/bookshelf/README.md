# 书架与阅读器

一个在 DeepSeek Harness 中管理和阅读本地 PDF、EPUB、TXT、Markdown 的插件。

书架只引用原文件位置，不复制、不修改、不移动、不删除原文件。阅读位置和已读状态保存在本机运行数据目录。

## 当前功能

- 通过 Host 文件浏览器添加单个文件或目录；目录只扫描第一层文件。支持拖入文件（取决于浏览器是否提供本地路径）。
- 按绝对路径去重：重复添加不会新增条目，也不会重置阅读进度或已读标记。
- 书架搜索、最近打开排序、PDF 当前页/总页数、其他格式百分比，以及“未开始 / 阅读中 / 已读完”状态；已读完由用户手动标记或取消。
- 书籍封面：EPUB 内嵌封面、PDF 第一页、TXT/Markdown 侧车图片；没有封面时显示格式占位图。
- 每本 PDF 独立记录阅读宽度/缩放；关闭再打开会恢复该书的宽度，不同书籍互不影响。
- 书架固定 4 列 × 3 行，每页 12 本；卡片间距加大，展示封面、格式/大小、进度和最近打开；超过 12 本提供页码、上一页和下一页。
- 添加窗口的“已添加”视图列出书架中已有路径，可在确认后直接移出；浏览文件时已添加文件显示标记。
- PDF 使用 PDF.js 渲染，恢复页码与页内滚动位置；EPUB 使用 EPUB.js，按 CFI 恢复；TXT 和 Markdown 按滚动比例恢复。
- Markdown 只读渲染并经过 DOMPurify 清理。
- 载入书架时检查原文件可用性：确认不存在标为“缺失”，权限不足或暂时不可访问标为“无法访问”；两者都不会自动移出书架。
- 阅读器右侧提供 Markdown 笔记侧栏，一本书可维护多份笔记；支持新建、切换、标题编辑、预览、自动保存和删除。
- PDF 阅读器提供文本层，可选中正文；未选中时取当前页文字作为问答上下文预览。
- PDF 阅读区支持用户主动截图，截取正文可视区域并预览、保留或取消；截图当前只保存在阅读会话内。
- EPUB/TXT/Markdown 支持选中文字；无选中时使用当前阅读范围的文本作为上下文预览。
- 问答标签可列出 DSH 已配置模型，使用默认模型或该书选择的模型提问；回答可加入当前笔记。
- 每本书的模型选择随笔记数据保存，重新打开继续使用；模型不可用或过期时需重新选择。
- 问答消息保存到 `$DSH_HOME/bookshelf/conversations.json`，重新打开可恢复；问答标签提供“清空对话”。
- 笔记按原书路径独立保存，移出书架后仍保留；书架新增“笔记数据”入口，可单独删除。
- “移出书架”只清除书目记录，原文件保留；重新添加按新书处理。

当前实现尚不提供 AI 问答、通用侧栏、OCR、朗读、云同步、正文编辑、书签、目录面板或阅读主题设置。

多份 Markdown 笔记已按阶段 A 实现；当前页/选中内容的 AI 问答仍待阶段 C。目标规则见 [功能规格](docs/spec.md)，更新记录见 [CHANGELOG](docs/CHANGELOG.md)。

## 安装

完整安装、升级和卸载步骤见仓库根目录的 [安装与升级插件](../../docs/installation.md)。

本插件包名为 `dsh-bookshelf`，目录为 `plugins/bookshelf`。从 checkout 安装的最短路径：

```sh
pnpm install
pnpm --filter dsh-bookshelf build
dsh plugin --profile web add "$PWD/plugins/bookshelf"
```

构建后会生成 `lib/index.js`、`lib/index.d.ts` 和 `lib/client.js`；`lib/` 被 `.gitignore` 排除，新 checkout 必须先构建。

## 使用

1. 打开侧栏的“书架”入口。
2. 选择“添加文件”或“添加目录”；目录只包含第一层支持的文件。添加窗口的“已添加”标签可查看已有路径并移出。
3. 点击书籍打开阅读器。返回书架会刷新阅读进度。
4. 打开阅读器后，右侧“笔记”面板可新建和维护多份 Markdown 笔记；书架顶部“笔记数据”管理仍保留的笔记。
5. 书架按 4 列 × 3 行、每页 12 本展示；超过 12 本使用页码、上一页和下一页。
6. 书架上的“重新检查”会重新检查所有已入架文件是否存在；缺失或不可访问的书目会在顶部集中提示。
7. “移出书架”需要确认，且不会删除原文件；笔记不会随移出删除。

### 本地文件路径

普通浏览器出于安全限制不会向网页暴露拖入文件的绝对路径。此时拖入会提示改用“添加文件”。DeepSeek Harness Desktop（Electron）或提供 `File.path` / `file://` URI 的载体可以直接按路径拖入。

## 封面

书架卡片会在能取得封面时显示封面，否则显示格式占位图：

- **PDF**：优先查找侧车图片；macOS 上使用系统 Quick Look 生成第一页缩略图，其他平台由浏览器 PDF.js 通过 Range 按需读取第一页（单本最多 6 MB Range 数据）。Range 打开失败且文件不超过 5 MB 时回退整本读取一次；更大的文件保留占位图。
- **EPUB**：读取 OPF 中的内嵌封面（`cover-image`、EPUB2 `meta name="cover"`、guide cover 或名称含 cover 的图片）；缺失时使用侧车图片。
- **TXT / Markdown**：使用与原书同目录的侧车图片。

侧车图片命名支持 `书籍名.cover.jpg`、`书籍名.cover.png`、`书籍名.cover.webp` 等，也支持 `书籍名.jpg`、`书籍名.png` 等同名图片；扩展名支持 jpg/jpeg/png/webp/gif/svg/avif/bmp。

封面按需读取，不写入书架记录，不创建书籍副本。PDF 第一页缩略图优先通过分段 Range 读取（单本最多 6 MB）并只缓存在浏览器内存；Range 失败时仅对不超过 5 MB 的文件回退整本读取一次。个别 PDF 无法渲染或解析时显示占位图，不影响书目、进度或阅读。

## 数据与隐私

- 书目、阅读位置和已读状态：`$DSH_HOME/bookshelf/library.json`（默认 `~/.dsh/bookshelf/library.json`）。
- 笔记：`$DSH_HOME/bookshelf/notes.json`，独立于书目记录。
- 问答消息：`$DSH_HOME/bookshelf/conversations.json`，独立于书目记录。
- 原书文件：保持在用户选择的位置，插件只读访问。
- 不创建书籍副本，不写回原文件。
- 封面从原文件或同目录侧车图片读取，不保存到书架记录；PDF 第一页缩略图只存在于浏览器内存。
- 书架记录按插件运行配置共享，不按聊天或工作目录分库。
- 写入使用临时文件加原子替换；写入失败不会提交内存中的新状态，也不会覆盖最近一次有效记录。
- 记录 JSON 损坏时，书架报告错误并停止写入，不会自动清空或重建书库。

## 支持格式

| 格式 | 阅读器 | 进度表示 | 封面 |
| --- | --- | --- | --- |
| PDF | PDF.js，单页视图；CMaps、标准字体和 WASM 随插件构建提供，未内嵌字体使用系统字体回退 | 页码 + 页内滚动比例，书架显示当前页/总页数；每本书记录阅读宽度 | 第一页缩略图；有侧车图片时优先侧车 |
| EPUB | EPUB.js 连续滚动，脚本内容禁用 | CFI + 百分比 | EPUB 内嵌封面；缺失时用侧车 |
| TXT | 等宽只读文本，UTF-8 解码 | 滚动比例 + 百分比 | 侧车图片 |
| Markdown | marked 解析、DOMPurify 清理、只读渲染 | 滚动比例 + 百分比 | 侧车图片 |

## 兼容性

- DSH：`>=0.2.1-rc.2 <0.3.0`（使用 `0.2.1-rc.5` 验证）。
- Node.js：`^22.19.0 || >=24.0.0`。
- 浏览器：DSH Web 当前支持的 Chromium；客户端 bundle 为 PDF.js 补充了 `Promise.try`、`Promise.withResolvers`、`Uint8Array` 基 64/十六进制和 `Map.getOrInsertComputed` 的兼容垫片。

## 初始版本取舍

当前按“先运行起来”的初始版本交付，以下两项是已确认的版本取舍，不阻塞本期验收：

- **普通浏览器拖入不引入受管导入副本。** 浏览器不会向网页暴露拖入文件的绝对路径；若为拖入创建副本，会违反 Spec“不创建书籍副本、只记录原文件位置”的约定。因此纯浏览器中提示改用“添加文件”，只有载体提供本地路径时才直接按路径入架。后续若需要纯浏览器拖入，应先明确是否允许受管副本，并同步修改 Spec。
- **PDF 使用单页视图。** 当前实现保存并恢复页码与页内滚动位置，满足本期位置恢复要求；连续滚动、文本层、目录和搜索属于后续阅读体验增强，不在初始版本内。

这两项已在初始版本确认；内部评审记录不随仓库发布。

## 已知限制

- 普通浏览器拖入文件无法取得本地路径；这是浏览器安全模型的限制，不是格式筛选问题。
- PDF 逐页渲染，不提供文本层、目录、搜索或注释；需要 CMaps 的 PDF 字体可能无法完美显示。
- EPUB 的 CFI 恢复在不同排版/窗口尺寸下可能落在近似位置；百分比依赖 EPUB.js 的位置索引生成。
- EPUB 封面按常见 OPF 结构解析；非标准命名、加密或特殊容器可能识别不到，此时显示占位图。PDF 默认以第一页作为封面；macOS Quick Look 不可用或非 macOS 环境下，个别 PDF 第一页无法在浏览器端渲染或超出封面读取预算时显示占位图。
- PDF 中未内嵌的 SimSun、SimHei、Cambria 等字体依赖浏览器系统字体回退；系统缺少对应字形时仍可能显示异常。
- 文件路径以字符串为唯一键；同一文件的符号链接或不同大小写路径可能被视为不同书目（符合“不同路径作为两本书”的约定）。
- 添加窗口的已添加视图只管理书目移出，不支持重命名、移动或打开原路径。
- 书架固定 4 列；窗口很窄时卡片会变窄，不切换为其他列数。页码超过 10 页时只显示“当前页 / 总页数”和上一页/下一页。
- macOS PDF 封面依赖系统 `qlmanage`；不可用时自动回退到浏览器 PDF.js。非 macOS 大 PDF 的封面受 6 MB Range/5 MB 回退预算限制。
- 书架卡片的次要操作使用图标按钮（已读标记、移出），以减少卡片内占用；悬停或读屏可获取完整操作名称。
- 不做跨 DSH 进程的写入协调；同一运行数据目录被多个进程同时修改时可能后写覆盖先写。
- 没有文件变化监听；目录添加后新增文件不会自动入架，需要再次添加。
- 未在 Windows、远程浏览器部署或其他 DSH 版本上逐一验证。

## 开发与验证

```sh
pnpm --filter dsh-bookshelf typecheck
pnpm --filter dsh-bookshelf test
pnpm --filter dsh-bookshelf build
```

测试覆盖路径识别与去重、目录第一层扫描、缺失/不可访问区分、进度与已读状态独立、移出后原文件保留、并发写入、损坏记录保护、书库替换失败备份恢复、RPC 与 Range 文件响应、每本书的阅读宽度持久化、EPUB 内嵌封面、侧车封面、cover 路由和 PDF.js 资源路由；添加窗口的已添加路径视图通过浏览器验证。

实际验证记录：

- `pnpm --filter dsh-bookshelf typecheck`：通过。
- `pnpm --filter dsh-bookshelf test`：8 个测试文件、49 个测试通过。
- `pnpm --filter dsh-bookshelf build`：生成 `lib/index.js` 与 `lib/client.js`。
- 临时 DSH profile（`0.2.1-rc.5`）中通过 Chromium 验证：书架面板加载、文件/目录添加、重复跳过、缺失与不可访问提示、保留/移出、PDF 翻页与页内位置恢复、EPUB 阅读与位置恢复、TXT/Markdown 进度恢复、Markdown XSS 清理、带路径的拖入、EPUB/TXT/PDF 封面与无封面占位图；代表性中文 PDF 的正文、公式与图片正常显示；PDF 宽度从 100% 调整到 120% 后关闭重开恢复 120%，重置适应宽度后记录为 100%；添加窗口已添加视图可列出路径、标记浏览中的已添加文件，并在二次确认后移出且保留原文件；书架分页在测试书库中验证：前四页各 12 本、最后一页剩余书目，末页下一页禁用，搜索后回到第一页；1672×941 视口下 4 列卡片约 313×210、间距 28px，3 行完整落在内容区内；阅读器笔记侧栏可新建两份笔记、切换并恢复，书架“笔记数据”入口可查看并按书删除；PDF 文本层可选中正文并生成上下文预览，阅读区截图可预览和保留；问答可调用 DSH 默认模型或该书选择的已配置模型，回答可加入当前笔记。
- 未验证：普通浏览器无路径拖入、Windows、远程部署、超大 EPUB、所有 PDF 的字体覆盖情况、非标准/加密 EPUB 封面、非 `0.2.1-rc.5` 的 DSH。
