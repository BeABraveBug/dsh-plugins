# Changelog

本文件记录 `dsh-bookshelf` 的用户可感知变化，遵循[书写规范](../../../docs/versioning-and-releases.md#changelog-书写规范)。发布日期使用北京时间。

## Unreleased

### Added

- 阅读器新增 Markdown 笔记侧栏，一本书可维护多份笔记，支持标题编辑、预览、自动保存和确认删除；保存状态与失败重试可见。
- 笔记按原书归一化路径独立保存，移出书架后保留，同一路径重新添加时恢复关联；书架“笔记数据”入口支持查看与按书删除，不删除原书或阅读进度。
- PDF 新增文本层和选中文字能力；PDF、EPUB、TXT、Markdown 可预览当前阅读内容或选中文字作为问答上下文，并支持展开查看和移除。
- PDF 支持截取正文可视区域，预览、保留或取消截图；截图仅保留在当前阅读会话，不发送给模型。
- 问答支持 DSH 已配置的默认模型与每本书保存的模型选择，围绕本轮文字上下文提问；模型凭据由宿主管理。
- 问答消息独立保存到 `$DSH_HOME/bookshelf/conversations.json`，重新打开可恢复消息列表，并可清空该书对话；目前请求模型时不携带历史轮次。
- 阅读侧栏采用紧凑笔记菜单、独立正文滚动与底栏保存状态；问答附件、输入、模型选择和发送集中在组合输入区，助手回答支持 Markdown 展示、复制与追加到当前笔记。

### Fixed

- 修复 PDF 文本层与画布错位导致无法选中文字的问题，并保留提取文本中的换行。
- 修复笔记保存请求期间继续编辑或加入回答时，新内容可能被误标为已保存的问题；关闭和切换前等待最新编辑内容保存成功。
- 修复对话写入失败后内存仍采用未保存结果的问题，避免后续写入间接提交失败的清空操作。
- 修复恢复已保存模型选择时的加载竞争，以及删除最后一份笔记会清除模型选择的问题。
- 修复侧栏尺寸变化时 PDF 未按正文宽度重新渲染的问题；页内位置保持与重新打开后的续读仍有缺陷，见[已知限制](../README.md#已知限制)。
- 修复 EPUB 跨章后问答上下文仍读取旧章节的问题，并支持后加载章节的文字选区。

当前未完成能力、已知问题和验证范围见 [README](../README.md#已知限制)；本记录不代表尚未实现的连续追问、历史来源快照、截图发送或对话数据管理已经交付。
