# Changelog

本文件记录 `dsh-bookshelf` 的用户可感知变化。日期使用北京时间。

## Unreleased

### Added

- 阶段 A：阅读器右侧 Markdown 笔记侧栏。
- 一本书支持多份笔记，可新建、切换、追加、修改标题、预览和删除。
- 笔记自动保存，并显示保存中、已保存和保存失败状态；保存失败保留输入。
- 笔记按原书归一化路径关联，移出书架后仍保留；同一路径重新添加时继续关联。
- 书架新增“笔记数据”入口，可查看仍保留的笔记并按书删除；删除笔记不删除原书或阅读进度。
- 新增独立 `$DSH_HOME/bookshelf/notes.json`，与 `library.json` 分离，使用原子写入与备份恢复。

### Added in Phase B

- PDF 文本层：支持选中正文文字，并将当前页或选中文字作为问答上下文预览。
- EPUB/TXT/Markdown 支持选中文字，并在无选中时提供当前阅读范围的文本上下文预览。
- PDF 阅读区截图：只截取正文可视区域，支持预览、保留和取消；截图目前仅保存在阅读会话内。

### Fixed

- 修正 PDF 文本层容器宽度为 0、与画布错位导致无法用鼠标选中文字的问题。
- 改进当前页文本提取：不再强制给每个文本项加空格，合并多余空格并保留换行。

### Added in Phase C (minimum path)

- 问答标签读取 DSH 已配置模型列表，并支持默认模型或当前会话内切换模型。
- Host 通过 `ctx.llm` 发送固定上下文和问题，收齐文本回答；凭据不进入浏览器。
- 回答可追加到当前 Markdown 笔记。
- 每本书选择的 `provider/model` 随书的笔记数据保存，重新打开继续使用；只允许 DSH 已配置模型。
- 问答消息持久化到 `conversations.json`，重新打开恢复；问答标签可清空当前书的对话。

### Fixed

- 修复笔记保存完成时丢弃请求期间新输入的问题。
- 修复对话写入失败仍提交内存状态的问题。
- 修复模型目录加载取消已保存模型恢复的问题。
- 修复删除最后一份笔记清除书籍模型设置的问题。
- 修复侧栏尺寸变化后 PDF 未重新适应的问题。
- 修复 EPUB 滚动后问答上下文仍停在开头的问题。

### Changed

- 阅读侧栏改为“专注书写”布局：笔记选择下拉、无边框标题/正文、底栏保存状态、折叠上下文附件和图标发送按钮。
- 笔记保存、加入回答和关闭前 flush 统一等待最新编辑版本。
- PDF 容器尺寸监听改为加载完成后绑定。

### Fixed

- 笔记保存 flush 循环提交最新编辑版本，加入回答同步递增 revision。
- PDF 尺寸观察在加载完成后的真实滚动节点上绑定。
- EPUB 按当前 CFI 的 sectionIndex 选择当前文档，不再固定首章。

### Not yet

- 发送给模型时的历史上下文拼接、截图附件持久化和对话数据管理入口仍待实现。
- 截图目前只保存在阅读会话内，问答按文字上下文发送。
