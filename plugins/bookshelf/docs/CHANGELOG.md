# Changelog

本文件记录 `dsh-bookshelf` 的用户可感知变化。日期使用北京时间。

## Unreleased

### Added

- 阶段 A：阅读器右侧 Markdown 笔记侧栏。
- 一本书支持多份笔记，可新建、切换、追加、修改标题、预览和删除。
- 笔记自动保存，并显示保存中、已保存和保存失败状态；保存失败保留输入。
- 笔记按原书归一化路径关联，移出书架后仍保留；同一路径重新添加时继续关联。
- 书架新增“笔记数据”入口，可查看仍保留的笔记并按书删除；删除笔记不删除原书或阅读进度。
- 新增独立 `$DSH_HOME/bookshelf/notes.json`，与 `library.json` 分离，使用原子写入与备份恢复。

### Not yet

- 阅读问答、模型选择、上下文快照和截图附件仍待后续阶段实现。
- PDF 文本层与选中文字提取仍待阶段 B。
