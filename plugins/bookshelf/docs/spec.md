# DSH Bookshelf Spec

状态：已确认的目标规格。现有功能与未验证范围见 [README](../README.md)。阅读问答的目标入口为独立通用会话插件提供的 DSH 右侧会话窗口；书架当前自带问答窗口保留，暂停继续扩展，通用会话接入与数据迁移尚未实现。封面书架、沉浸阅读、PDF 两侧翻页、独立页与全屏入口已实现；笔记创建位置跳转与下文阅读问答目标尚未全部实现。

## 目标与范围

在 DSH 内管理和阅读本地 PDF、EPUB、TXT、Markdown，优先保证 PDF 阅读体验。范围包含添加书籍、阅读与续读、书架进度展示、书架封面展示、已读标记、文件可用性检查、移出书架，以及阅读侧栏中的 Markdown 笔记与当前页或选中内容的 AI 问答。

本期不包含整本书检索问答、通用侧栏、OCR、朗读、云同步或原书正文编辑。

## 独立书架页面与全屏阅读

DSH 内的书架提供“独立打开”入口，在新的浏览器页面展示完整书架；阅读器也可独立打开当前书籍并恢复该书已保存的阅读位置及缩放。独立页不显示 DSH 的聊天区、工作区导航、会话列表或全局侧栏，书架与阅读器占据页面可用区域；从阅读器返回书架仍留在独立页，不跳回 DSH 聊天布局。原有嵌入 DSH 的书架入口继续保留。

独立页提供基础浅色与深色显示，但与 DSH 的完整主题同步不作为当前版本的验收条件；固定偏好、系统切换或缓存条件下，两者配色可能不同。主题不可用或缓存失效时不得阻断书架启动、阅读和笔记。PDF 原页颜色不因界面深色模式而自动反色。

独立页沿用当前 DSH 运行配置的书库、笔记和阅读记录；添加、阅读、翻页、保存及移出使用相同规则，不复制书库、不将原书转换为浏览器直接读取的 file URL。独立的是页面布局，DSH 服务仍需运行；服务不可达或认证失效时明确提示，不将本地未确认状态显示为已保存。已认证用户可刷新或重新访问该页，未认证访问不能读取书库与原书，按宿主支持的方式完成认证后再打开。

阅读器提供用户主动触发的全屏与退出全屏入口。支持浏览器全屏时使用浏览器能力，退出后保留当前书籍、位置及缩放，仍在独立阅读页；全屏不可用或被拒绝时保留独立页阅读并说明原因。不自动强制进入全屏，也不通过 CSS 铺满页面冒充已经进入浏览器全屏。必要阅读控件、返回入口、键盘焦点和退出操作保持可达；笔记可收起，通用 AI 会话插件未接入不阻塞独立阅读。

独立页和 DSH 内页面共享同一份权威数据。后台阅读窗口不继续定时提交旧位置覆盖前台阅读；同一本书的并发进度写入不得由迟到的旧请求覆盖更新的有效位置，其他书籍的阅读状态彼此独立。不承诺关闭页面能完成尚未确认的异步保存，保存失败或未完成应有可辨识状态。

## 原文件与书架记录

书架记录原文件位置和书目、阅读状态；笔记与问答记录独立于原书保存。不修改、移动、删除原文件，也不创建书籍副本。阅读直接使用原文件。书目和阅读记录在重新打开书架后保留，除非用户主动移出对应书籍。

同一插件运行配置使用一套书目与阅读进度；切换聊天或工作目录不切换书库。此范围不包含跨 DSH 运行配置或跨设备共享。

## 添加书籍

提供三种入口：选择单个文件、选择目录、拖入文件。三种入口采用相同的格式筛选和去重规则，支持 PDF、EPUB、TXT、Markdown。

目录添加只扫描所选目录直接包含的文件，不扫描子目录。它是一次性操作：后续新增文件不自动入架，需要再次添加目录或文件。

按文件路径去重：相同路径再次加入时直接跳过，不重复入架，不要求逐本确认；已有阅读进度和已读状态不因重复添加而重置。不同路径即使内容相同也作为两本书，不做内容比对或跨路径合并。

添加窗口提供“已添加”视图，列出书架中已有的路径，并允许用户从该视图移出书目。浏览文件时，已添加的文件显示标记。

## 界面布局

书架首页以封面浏览为主，不增加紧凑书目视图。每本书显示封面、最多两行的书名及阅读进度；截断后仍能通过可操作的详情入口查看完整书名，不能仅依赖鼠标悬停。封面不可用时沿用格式占位图，缺失或不可访问提示保持可辨识。

点击封面或书名打开该书并恢复阅读位置，不在每张卡片重复放置“继续阅读”按钮。标记/取消已读和移出收纳至该书的更多菜单，菜单操作不触发打开书籍；移出仍需确认，数据保留规则不变。原文件路径与文件大小在详情中查看，不占用主浏览区域。

书架顶部保留标题、搜索、添加书籍与独立打开入口；添加入口仍能分别选择文件和目录。笔记数据与文件可用性重新检查收纳至管理入口，不能因精简布局移除这些能力。保持最近打开排序与分页，窄窗口不产生整页横向滚动。

阅读页采用紧凑标题与工具区，正文位于剩余空间中央。保留返回书架、页码跳转、上一页/下一页、缩放、适应宽度、截图、全屏、独立打开、笔记与已读操作；低频操作可收纳，但必须可达。标题过长或窗口变窄时工具区可换行，不能覆盖正文、选字层或侧栏。PDF 原页比例与颜色不因布局改版改变。

笔记侧栏在没有保存过界面偏好时默认收起；用户展开/收起和调整宽度后，同一浏览器及同源下的两个入口在重新打开时恢复最近偏好。宽度须适配当前窗口，不得挤掉正文；窄窗口可改为堆叠显示。偏好不可读或保存失败时使用默认值，不能阻断启动、阅读或笔记保存。收起前沿用最新笔记保存与失败保留输入的规则，不通过隐藏侧栏丢弃编辑。

DSH 内嵌与独立页复用书架和阅读布局；独立页去除 DSH 导航，利用可用区域。独立页仍依赖 DSH 服务，主题同步的既有验收豁免保持有效。界面改版不扩展书架自带 AI 问答窗口，不删除既有问答入口和记录。

## 阅读与进度

阅读位置自动保存，下次打开同一本书恢复上次位置。PDF 恢复页码及页内位置。

书架展示每本书的阅读进度：PDF 显示当前页与总页数；EPUB、TXT、Markdown 显示百分比。尚未打开的书标为“未开始”。

书架采用封面优先的 4 列 × 3 行网格，每页最多 12 本；窄窗口降为 3 列或 2 列，不产生整页横向滚动。超过 12 本时提供页码、上一页和下一页。搜索或筛选后回到第一页。

PDF 的阅读宽度按书籍保存，重新打开同一本书时恢复该书的宽度；“适应宽度”作为默认宽度（1 倍）记录。不同书籍的宽度互不影响。

PDF 阅读区增加两侧翻页入口，同时保留工具栏的上一页、下一页及页码跳转。鼠标靠近阅读视口左侧或右侧时，在对应侧显示可点击的上一页或下一页指示；鼠标移开后隐藏，键盘聚焦入口时仍可见。悬停本身不翻页，每次点击翻动一页，新页从页首显示，沿用现有进度保存与相对缩放语义。

两侧入口固定在正文阅读视口内，不随页面正文滚走，不以整个浏览器窗口或笔记侧栏的边缘定位；展开、收起或拖动侧栏后随实际阅读区调整。指示不覆盖工具栏、滚动条、笔记和问答控件，不以透明的大块点击区域拦截正文选字、拖选或滚动。第一页的上一页、末页的下一页不可触发；总页数未知、文档加载失败时不提供可执行的翻页入口。窄窗口、触屏或无法悬停时仍可使用原工具栏，不以悬停作为唯一操作方式。

“已读完”由用户手动标记，也可取消并恢复为“阅读中”。翻到末尾或显示 100% 不自动标为已读完。标记与取消标记均不重置阅读位置。

## PDF 目录导航与页面引用

PDF 阅读器只有一个“目录”入口。有内嵌目录时显示可展开的章节树；目录项带有效目标页时可跳转。没有可用内嵌目录时，同一面板显示带页码的页面缩略图，缩略图按需加载并高亮当前页。导航读取或单页缩略图失败不阻断正文；窄窗口使用抽屉。

笔记可插入当前 PDF 当前页的引用，也可从书架选择另一本 PDF 并指定页码。第一版引用使用 PDF 实际页序并跳到页首，不做印刷页码换算。引用固定书籍和位置，后续翻页不改变已有引用。

同书引用在当前阅读区跳转；跨书引用新开独立阅读页，打开目标书并跳到引用页，保留原阅读页和笔记。跨书打开直接更新目标书的阅读进度。书籍不可用、引用失效或页码越界时明确提示，不静默落到边界页或同名书籍。

## 封面展示

书架在能够取得封面时显示封面，否则显示格式占位图。

- PDF 优先使用同目录侧车图片；没有侧车图片时使用第一页作为封面。
- EPUB 优先使用内嵌封面；没有内嵌封面时使用侧车图片。
- TXT、Markdown 使用与原书同目录的侧车图片（`<文件名>.cover.<图片扩展名>` 或 `<文件名>.<图片扩展名>`）。
- 封面从原文件或侧车图片读取，不写入书架记录，也不创建书籍副本。
- 封面读取失败、文件缺失或格式不支持时保留书目并显示格式占位图，不影响阅读进度和阅读。

## 文件可用性检查

载入书架时检查已入架文件是否可访问，不借此扫描添加目录中的新书。

确认不存在的文件标记为缺失，并集中提示用户选择保留条目或移出书架，不自动移出。

暂时无法访问、权限不足等不能确认文件已删除的情况，提示无法访问，不直接当作已删除处理。检查异常不清空书库或阅读记录。

## 移出书架

提供统一的“移出书架”操作，同时清除该书的书架条目、阅读进度和已读状态，不保留这些记录。

移出不删除或修改原文件。重新添加已移出的书籍时，按新书处理，不恢复此前进度与已读状态。缺失文件通过同一移出操作处理。

笔记和问答记录不随移出操作删除。移出确认中说明这些数据将保留；相同归一化路径重新入架时重新关联保留的数据，阅读进度与已读状态仍按新书处理。提供独立、明确的数据删除入口，不能把移出书架当作删除笔记或对话的授权。

## 阅读侧栏与笔记

阅读器提供可展开、收起及调整宽度的笔记侧栏；阅读问答使用通用会话插件提供的 DSH 右侧会话窗口。切换笔记与会话入口保留各自内容；侧栏尺寸变化后，正文按可用空间重新计算适应宽度，保留该书的相对缩放比例。现有书架“笔记／问答”标签在接入迁移前保留，不因确定目标入口而删除已有内容。

一本书可关联多份 Markdown 笔记。用户可以新建笔记，也可选择已有笔记持续追加；支持修改标题、编辑、预览和确认后删除；Markdown 阅读与笔记预览共用 GFM、LaTeX 公式及 Mermaid 图表渲染，保留可编辑原文，图表失败不能阻断编辑或保存。笔记彼此独立，删除其中一份不删除其他笔记或对话。

笔记自动保存。切换笔记时先保存当前内容，再完成切换；再次打开书籍时恢复上次编辑的笔记。保存中、已保存和保存失败有明确提示；保存失败保留输入，不通过切换丢弃未保存内容。

笔记可关联阅读位置。阅读中新建笔记自动附带创建位置的跳转入口；继续编辑不受该位置限制，允许记录多个章节的内容。

## 阅读 AI 问答

书架向通用会话插件提供书籍身份、阅读内容和来源位置，并提供回到原文与加入笔记的操作。临时／持久会话的通用交互、模型调用和历史管理由会话插件承载。具体会话数量、临时会话清理时机、上下文预算、公开接口和旧记录迁移规则另行确认；不把现有书架消息数组直接当作通用会话已经接入。接入前保留现有功能与数据，暂停扩展书架独立问答窗口。会话插件未就绪或不可用不影响阅读和笔记。

问答围绕当前页或用户选中的内容，支持连续追问。有选中文字时优先附带选中内容，否则附带当前页；发送前展示本次附带的范围，允许查看内容或移除附件。

发送时固定本轮附带的内容与阅读位置。翻页不改变已发送问题的上下文；新页面在下一次发送时明确附带，历史消息保留各自的引用内容与位置。

用户可将回答内容加入笔记，选择追加到已有笔记或新建笔记，保留对应书籍位置；插入后可自行编辑。未经用户操作，回答不自动写入笔记。

PDF 有文字层时，选区覆盖应与可见文字的字号、位置、方向及缩放一致；选区变化不能被旧页或旧缩放的异步文字层覆盖。无可提取文字的页面明确提示无法直接选字或取得文字上下文，不把扫描页空文本当成已经附带正文，也不自动引入 OCR。

上下文读取或模型请求失败时明确提示，不将未取得的页面内容宣称为已附带，不影响原书阅读、已有笔记和已保存对话。

## 验收标准

- 三种添加入口均可加入支持格式的文件；相同路径重复添加不新增条目、不重置已有状态；不同路径的相同内容可分别入架。
- 同一插件运行配置中，切换聊天或工作目录后仍显示同一套书目与进度。
- 目录内直接包含的支持文件可入架，子目录中的文件不入架；目录后来新增文件不自动入架。
- 添加窗口的“已添加”视图能查看已有路径并确认移出；浏览时已添加文件有标记，移出后原文件仍在。
- 添加、阅读和移出前后，原文件内容保持不变，未创建书籍副本。
- 阅读后关闭并重新打开，书目和位置仍在，PDF 回到保存的页码与页内位置。
- 可从 DSH 打开独立书架页，也可独立打开当前书籍；页面不含 DSH 聊天与全局导航，返回书架不离开独立页。刷新或重新访问后使用同一配置下的书库，未认证或服务不可达不能越过宿主访问原书。
- 独立页可主动进入和退出浏览器全屏；退出不丢书籍、位置、缩放或已保存笔记，全屏不可用时仍可正常阅读。原嵌入入口继续可用，多窗口不以后台旧位置覆盖新进度。
- 调整 PDF 阅读宽度后关闭并重新打开，恢复该书宽度；其他书籍保持各自宽度。
- PDF 鼠标移至正文视口两侧显示对应翻页指示，离开隐藏；键盘聚焦时可见并能操作。悬停不翻页，单击只翻一页；首末页边界不越界。工具栏入口保留，正文选字、拖选、滚动与侧栏操作不被覆盖；侧栏尺寸变化后指示仍位于正文视口内。
- 书架显示约定格式的进度，未打开书籍显示“未开始”。
- 书架采用封面优先网格，每页最多 12 本；内容区变窄时减少列数，最后一页显示剩余书目。长书名最多显示两行且可查看全文；更多菜单操作不误开书籍，移出仍有确认。
- 在 320、768、1280 像素的可用宽度下，书架与阅读工具可达且无整页横向溢出；新增入口不覆盖正文选字、滚动条或笔记。
- 清除界面偏好后首次阅读的笔记默认收起；调整开合与宽度后重开可恢复，独立页沿用同源偏好；偏好损坏或禁用存储时仍能启动与阅读。收起笔记仍等待最新保存，失败时保留输入。
- 有内嵌封面的 EPUB、PDF 第一页或侧车图片、TXT/Markdown 侧车图片可以显示为封面；无封面或封面读取失败时显示格式占位图，且不影响书架记录。
- 到达末尾不自动标为已读完；手动标记与取消不改变保存位置。
- 原文件被删除后，载入书架出现缺失提示；用户选择保留时，条目仍在。
- 文件暂不可访问时，不自动移出书架或丢弃阅读记录。
- 移出后原文件仍在，书目和阅读记录消失；再次添加显示为未开始。
- 侧栏可收起、调整宽度及切换笔记/问答；切换不丢失内容，正文继续按该书的相对缩放比例适应可用宽度。
- 同一本书可创建多份笔记、切换并分别追加内容，支持修改标题和 Markdown 预览；重新打开恢复上次编辑的笔记。
- 笔记保存失败时输入保留并显示失败，不通过切换丢失输入；删除需确认且不影响其他笔记、对话或原书。
- 阅读中新建笔记带有可跳转的创建位置，后续可继续记录其他章节。
- 提问前可查看或移除选中内容或当前页附件；发送后翻页不改变该消息的引用内容与位置，连续追问仍可使用已有上下文。
- 通用会话接入后可从书架打开阅读问答并附带内容与来源，回答的来源操作仍指向对应书籍；会话插件不可用不阻断阅读与笔记。接入迁移前已有问答记录保留，不因暂停扩展而丢失。
- 用户能将回答内容及来源位置追加到指定笔记或新建笔记，并继续编辑；模型请求失败不损坏已有数据。
- 移出前明确提示保留笔记和对话；移出后数据仍在，同一路径重新添加时重新关联，同时阅读进度与已读状态按新书处理。
- 笔记和对话的数据删除使用独立明确的入口，不因移出书架而发生。
