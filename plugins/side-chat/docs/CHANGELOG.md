# 更新记录

## Unreleased

### Added

- 侧聊改为插件独立会话：SQLite 保存侧聊、消息、引用、背景快照与模型覆盖，不再创建 DSH 原生会话。
- Host 使用 DSH 默认模型完成文字问答；每侧聊可覆盖模型，默认跟随当前配置。
- 全量发送侧聊历史；模型上下文不足时明确报错并保留输入。
- 首轮无引用时自动附加主会话背景（8000 字符预算、冻结快照、正文不重复显示）。
- 主会话选文引用、按 Parent 分组、关闭/恢复、归档等待、统一归档与永久删除插件数据。
- 旧版 `state.json` 启动时清理；旧 DSH 侧聊保留原工作区，不导入、不删除。

### Changed

- 默认移出改为归档；归档请求禁止新提交，生成中的任务结束后转为只读。
- 永久删除只处理插件数据，必须单独确认。

### Removed

- 创建 DSH 会话、DSH Session 恢复/事件对账、工具授权卡片与宿主归档同步设想。
