# 更新记录

## Unreleased

### Added

- 建立 `dsh-side-chat` 插件骨架：包清单、Host 与 Client 构建入口、本地化资源、构建与检查脚本。
- 在右侧栏注册「侧边对话」标签与面板，并从右栏指南和会话头部打开；收起与切换会话时保留已访问面板。
- 多侧聊的新建、切换、关闭并保留、恢复与只读归档；草稿、引用、背景快照、管理状态与真实会话映射持久化，刷新后恢复。
- 首次发送创建加入父会话工作区的真实 DSH 会话；失败原因、中断、输出上限与关联会话失效会在面板中提示。
- 主会话选文浮层支持用户消息、助手消息与代码块；引用可单条移除或一键清空，发送后保留来源快照。
- 首轮无主动引用时自动附加主会话背景（8000 字符预算、按预算补读历史、超长单条标节选）；背景正文不在侧聊消息区重复显示。
- 侧聊内可显示并回答工具授权（允许一次 / 拒绝），展示同 `callId` 的调用参数与宿主本地化原因，参数可展开全文或复制。
- 长侧聊提供「加载更早消息」。

### Changed

- 移除“删除侧聊（仅移除插件记录）”入口；默认移出改为归档，永久删除待宿主能力与独立确认后另行提供。
- 移除「无上下文 / 主会话摘要」手动选择；背景改为按首轮引用情况自动决定，名称统一为「主会话背景」。

### Fixed

- 归档等待中若上一条提交结果未知，按 `requestId` 在会话历史中只读对账；找到时按正常成功结算引用与草稿，找不到时由用户确认未提交；确认动作会复核会话、任务状态并再次查历史。
- 统一归档视图包含「归档中」项，跨 Parent 可见等待状态。
- 背景取材遇到放不下的完整消息即停止补读，不再为凑满 8000 字符继续拉取历史直至失败。
- 归档在创建身份持久化返回后再次检查，避免归档后仍新建真实空会话。
- 移除基于旧列表状态的自动归档；无法确认删除时只提示并保留侧聊。
- 背景补读失败、无进度或达到页数上限仍未读完时整次获取失败，保留草稿且不发送，不再把部分内容当完整背景。
- 背景获取开始时冻结来源截止范围，补读期间新增的主会话消息不进入快照。
- 旧侧聊按已交付背景或真实消息推断首轮已完成，升级后不会重新注入背景。
- 背景显示只剥离本聊天快照生成的精确包裹，问题里出现同名标记文字时不再被误删或暴露背景后缀。
- 归档侧聊查看时隐藏操作菜单；归档开始时、创建会话前和提交前都会拒绝新发送。
- 自动归档前刷新会话列表并核对 Workspace 归档集合；无法确认删除时只提示，不自动归档。
- 授权参数、本地化原因与调用详情展示；找不到调用详情时禁用批准。
- 记录加载完成前拒绝整份写入并禁用发送，避免慢加载或加载失败时覆盖已有记录。
- `gateway/cancelled`、`gateway/internal` 等 carrier 结果按未知处理，只有明确表示未接收的业务拒绝才允许直接重试。
- 发送前持久化提交身份；创建身份每次先落盘；失败重试复用同一会话标识。
- 同步 `retain` 抛错不再缓存 rejected attempt；失效会话恢复失败不随渲染重复重试。
- 合并加载前新建的侧聊/引用并立即保存，避免刷新丢失。
- 发送期间新增的草稿与引用不再被上一轮成功清空；对账成功补记背景交付。
- 主会话助手消息与代码块可选文；`forked` 不再清除既有失败。
- 归档只读状态、删除确认范围说明、引用清空与来源保留。
